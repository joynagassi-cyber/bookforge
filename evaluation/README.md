# Evaluation Suite

BookForge must be evaluated as a system, not only by final prose quality.

## Test families

### Routing
Does a small change avoid the full-book workflow?

### Context
Does the writer receive all required facts and minimal irrelevant context?

### Continuity
Can the system preserve entity state across long manuscripts?

### Voice
Does revision preserve author-specific characteristics?

### Integrity
Does the system distinguish uncertainty, citation gaps and similarity signals?

### Anti-slop
Does reducing genericness preserve good style instead of flattening prose?

### Robustness
What happens when canonical artifacts disagree?

### Portability
Does the same task packet work across different runtimes?
