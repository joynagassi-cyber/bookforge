# BookForge Planning Directory

This directory contains planning artifacts that guide the book production workflow.

## Contents

- `brief.md` - Project brief and goals
- `research.md` - Research findings and sources
- `positioning.md` - Market and audience positioning
- `timeline.md` - Production timeline and milestones

## Rules

1. Planning artifacts are created during Phase 1 (Analysis)
2. Planning artifacts are read-only during downstream execution
3. Changes to planning artifacts require upstream re-validation
4. All planning decisions must be logged in paper-trail.md
