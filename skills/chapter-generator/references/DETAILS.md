# chapter-generator — Detailed Reference

## Chapter Patterns

### Fiction: Scene → Complication → Choice → Consequence
Use this pattern for literary fiction, thrillers, and narrative nonfiction.

**Structure:**
1. **Scene**: Establish setting, characters, and normal state
2. **Complication**: Introduce conflict, obstacle, or problem
3. **Choice**: Character makes a decision or takes action
4. **Consequence**: Show the result of that choice

**Warnings:**
- Avoid repetitive beat cadence — vary sentence length and paragraph structure
- Don't resolve all complications in one chapter — leave threads for later
- Ensure consequences create new complications, not just closure

### Thriller: Setup → Reversal → Escalation → Hook
Use this pattern for suspense and thriller genres.

**Structure:**
1. **Setup**: Establish stakes and normal world
2. **Reversal**: Something changes the situation unexpectedly
3. **Escalation**: Tension increases, options narrow
4. **Hook**: End with a cliffhanger or revelation

**Warnings:**
- Watch for artificial cliffhangers — make them earned
- Don't overuse reversals — one per chapter maximum
- Keep stakes clear and escalating

### Nonfiction: Problem → Mechanism → Application
Use this pattern for business, self-help, and instructional books.

**Structure:**
1. **Problem**: Define the problem clearly with evidence
2. **Mechanism**: Explain the solution/framework
3. **Application**: Show how to apply it with examples

**Warnings:**
- Avoid repeating framework language without new examples
- Don't hide weak evidence — be transparent about limitations
- Make applications concrete and actionable

### Memoir: Event → Sensory Detail → Reflection → Meaning
Use this pattern for personal narrative.

**Structure:**
1. **Event**: Tell what happened (scenes, not summaries)
2. **Sensory Detail**: Add sights, sounds, smells, textures
3. **Reflection**: Share what you were thinking/feeling
4. **Meaning**: Reveal why this matters now

**Warnings:**
- Do not over-explain meaning — let readers draw conclusions
- Avoid hindsight bias — show uncertainty in the moment
- Balance scene and reflection — too much reflection becomes lecture

## Voice Profiles

### Mentor (experienced guide)
- **Cadence**: Measured, deliberate pacing
- **Sentence shape**: Varied, authoritative but not pompous
- **Lexical profile**: Precise, concrete, avoids jargon
- **Relationship**: Guides without condescension
- **Use when**: Teaching complex topics, explaining frameworks

### Companion (trusted peer)
- **Cadence**: Warm, conversational
- **Sentence shape**: Short to medium, accessible
- **Lexical profile**: Personal, relatable, inclusive
- **Relationship**: Walks alongside the reader
- **Use when**: Personal stories, emotional topics, building trust

### Investigator (curious analyst)
- **Cadence**: Probing, question-driven
- **Sentence shape**: Mixed, analytical
- **Lexical profile**: Evidence-heavy, precise
- **Relationship**: Invites scrutiny and testing
- **Use when**: Research books, data analysis, critical thinking

### Storyteller (narrative guide)
- **Cadence**: Rhythmic, varied
- **Sentence shape**: Mixed, descriptive
- **Lexical profile**: Sensory, specific, vivid
- **Relationship**: Immerses the reader
- **Use when**: Fiction, memoir, narrative nonfiction

### Teacher (clear instructor)
- **Cadence**: Steady, logical
- **Sentence shape**: Structured, pedagogical
- **Lexical profile**: Definitions + examples
- **Relationship**: Explains and tests understanding
- **Use when**: Instructional content, how-to guides

### Witness (first-person experiencer)
- **Cadence**: Irregular, authentic
- **Sentence shape**: Natural, unpolished
- **Lexical profile**: Concrete, reflective
- **Relationship**: Shares without overclaiming
- **Use when**: Memoir, personal essays, experiential accounts

## AI Slop Patterns to Avoid

| Pattern | Signal | Repair Direction |
|---------|--------|-----------------|
| Generic opening | Abstract throat-clearing | Start with the first useful fact or scene |
| Triplet overuse | Repeated three-item lists | Vary structure and merge redundant items |
| Formulaic transition | Predictable transitions | Use causal or semantic transitions |
| Abstract density | High abstract-noun ratio | Replace abstractions with observable specifics |
| Empty emphasis | Importance without evidence | Add evidence or remove claim |
| Summary loop | Paragraph repeats previous | Delete or add substantive advancement |
| Promotional inflation | Revolutionary/transformative | State exact benefit and limits |

## Cliches to Replace

| Cliche | Replacement Strategy |
|--------|---------------------|
| "This will change your life" | Replace with a concrete outcome |
| "A journey of self-discovery" | Name the actual transformation |
| "In today's fast-paced world" | Start with a concrete fact, scene, question or claim |
| "In conclusion" | Use a substantive closing transition or none |
| "At the end of the day" | State the exact idea |
| "Game changer" | Specify what changes and by how much |

## Quality Targets by Genre

### Fiction
- continuity: Track characters, settings, timeline
- dialogue: Natural, distinctive voices
- show-dont-tell: Scene over summary
- pacing: Vary sentence length for rhythm
- tension: Maintain stakes throughout

### Nonfiction
- structure: Clear argument progression
- facts: Verified claims with sources
- citations: Proper attribution
- voice: Consistent tone throughout
- application: Concrete examples

### Memoir
- authenticity: Honest emotional reflection
- sensory detail: Concrete memories
- voice: First-person perspective maintained
- meaning: Insight emerges naturally
- privacy: Respect for real people
